Specifications

Drawing tools
Pencil, Eraser, Fill, Line, Rectangle, Ellipse, Diamond, Triangle and Color Picker. Brush sizes 1 to 4. Shapes can be outline or filled. Right mouse button erases.
Shortcuts
B pencil, E eraser, F fill, L line, R rectangle, C ellipse, D diamond, T triangle, P picker. Ctrl+Z undo, Ctrl+Y redo, Ctrl+S save, Ctrl+O open.
Colors
A palette of 36 colors plus a custom color chooser.
Canvas
16×16, 32×32, 64×64, 128×128, 256×256 and 512×512. Transparent checkerboard background. Zoom from 0.25× to 24× with the mouse wheel. Pan with the middle mouse button.
Layers
Multiple layers in every frame. Add, remove, and move layers up or down.
Animation
Frame timeline with up to 120 frames. Playback up to 60 FPS. Onion skin. Frame editor.
Auto Rig
Split a character into parts, set pivot points, and animate each part on its own.
Import
Import a PNG image as the animated object.
Save and export
Save and open projects as .pixelart files. Export the current frame as PNG. Export the whole animation as a sprite sheet PNG.
Library
A project gallery with thumbnails for your saved projects and exported images.
Safety
Auto-save every 60 seconds with drawing recovery after a crash. Undo and redo.
Appearance
Light mode and dark mode.
Built with
Python and Tkinter.
